# AI-Powered Data Analytics Assistant

## Overview

AI-Powered Data Analytics Assistant is an intelligent analytics platform that automates data cleaning, exploratory data analysis (EDA), customer feedback analysis, and executive reporting. By combining traditional data analytics with Large Language Models (LLMs), the application enables users to analyze datasets, generate insights, ask questions in natural language, and create business-ready reports.

---

## Problem Statement

Analyzing raw datasets often requires multiple tools for cleaning, visualization, and reporting. This project streamlines the entire analytics workflow into a single platform, reducing manual effort and enabling faster, AI-assisted decision-making.

---

## Key Features

### 📊 Data Analytics

* Upload CSV and Excel datasets
* Automated data cleaning and preprocessing
* Missing value handling and duplicate detection
* Exploratory Data Analysis (EDA)
* Dataset quality assessment
* Export cleaned datasets

### 📈 Interactive Visualizations

* Distribution and trend analysis
* Correlation analysis
* Category-wise insights
* Interactive business dashboards

### 🤖 AI Analytics Assistant

* Natural language interaction with datasets
* Context-aware business insights
* Automated trend interpretation
* Executive summary generation

### 💬 Customer Feedback Analytics

* Sentiment Analysis (Positive, Neutral, Negative)
* Topic extraction
* Review summarization
* Customer opinion analysis

### 📄 Executive Reports

* Automated business reports
* Key findings and recommendations
* Executive-ready summaries
